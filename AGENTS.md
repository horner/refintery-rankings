# Repository guidance for coding agents

Read [CONTRIBUTING.md](CONTRIBUTING.md) before preparing changes or a pull request.

For changes to the published site, data, generated output, or publishing behavior, provide a working GitHub Pages preview from the contributor's own fork before requesting merge. Include the preview URL, deployed PR commit SHA, successful workflow-run link, and browser checks in the PR description. Follow the documentation-only exception in CONTRIBUTING.md when it applies.

Keep preview deployments in the contributor's fork. The upstream `main` branch publishes the live site.
